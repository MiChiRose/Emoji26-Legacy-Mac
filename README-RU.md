# Emoji26 Legacy Mac

Безопасный сборщик обратимого дополнительного emoji-шрифта для Intel Mac с
финальными версиями OS X/macOS 10.8–10.13.

В репозитории находятся только исходники. Здесь **нет** Apple Color Emoji,
готового шрифта или готового установочного пакета. Пользователь самостоятельно
собирает пакет из шрифтов, скопированных с принадлежащих ему установок macOS.

[English README](README.md)

## Что делает проект

Сборщик сравнивает `Apple Color Emoji.ttc` из macOS 26 со штатным emoji-шрифтом
целевой старой системы. Он создаёт отдельный шрифт
`Emoji26 Additions.ttf`, содержащий только безопасные одиночные code points,
которых не было в старом шрифте.

Установщик добавляет `/Library/Fonts/Emoji26 Additions.ttf`. Штатный Apple Color
Emoji и системная Character Palette не заменяются. В комплект собирается
лёгкий AppKit-picker: он нужен потому, что база старой Character Palette не
содержит новые символы.

## Реальный статус совместимости

| Система | Статус |
| --- | --- |
| OS X 10.9.5, Intel x86_64 | На реальном Mac подтверждены process-local загрузка CoreText и цветная `sbix`-отрисовка |
| OS X 10.8.5 | Цель сборки реализована; установка и отображение ещё не проверены |
| OS X 10.10.5–10.13.6 | Цели сборки реализованы; установка и отображение ещё не проверены |

Наличие цели сборки не означает доказанную совместимость. Каждый пакет
привязан к одной точной версии ОС и откажется устанавливаться на другой.
Подробности: [тест Mavericks](research/TEST-MAVERICKS-10.9.5.md).

На 10.9.5 без установки подтверждено, что CoreText загрузил дополнительный
шрифт и цветно отрисовал `U+1FAE8`, `U+1FAE9` и `U+1FA8A`. Системный fallback
после установки, работа после перезагрузки и удаление ещё требуют ручного
теста.

## Что понадобится

- Современный Mac с macOS 11 или новее для скачиваемого мастера.
- Собственный `Apple Color Emoji.ttc` из установленной macOS 26 или
  официального установщика Apple.
- Неизменённый штатный Apple Color Emoji от точной целевой версии старой ОС.
- Целевой Intel Mac x86_64 с одной из версий:
  `10.8.5`, `10.9.5`, `10.10.5`, `10.11.6`, `10.12.6`, `10.13.6`.

Сторонние зеркала шрифтов и неизвестные бинарники использовать нельзя.

## Самый простой вариант: готовый мастер

Скачайте `Emoji26-Installer-Builder-0.2.0-alpha.1.zip` из prerelease на GitHub,
распакуйте его и дважды нажмите `Make Emoji Installer.command`.

Если Gatekeeper предупредит о неподписанной исследовательской сборке, нажмите
на command-файл с зажатой Control, выберите **Открыть** и подтверждайте запуск
только после сверки ZIP с приложенным файлом `.sha256`.

Мастер попросит выбрать:

1. Ваш `Apple Color Emoji.ttc` из macOS 26.
2. Неизменённый штатный Apple Color Emoji от точной целевой старой ОС.
3. Точную версию целевой ОС.

После этого персональный `.pkg` будет создан локально и показан в Finder. В
скачиваемом ZIP находятся только открытые исходники и скомпилированные
инструменты нашего проекта. Шрифтов Apple в нём нет, файлы никуда не
отправляются, а на современный Mac ничего не устанавливается. Для этого
варианта не нужны Xcode, Python или Homebrew.

Созданный персональный `.pkg` уже содержит производные данные глифов Apple.
Храните его только для собственных Mac и не распространяйте.

## Сборка

Пример для Mavericks 10.9.5:

```sh
./build-payload.command \
  --font "/Volumes/macOS 26/System/Library/Fonts/Apple Color Emoji.ttc" \
  --legacy-font "/путь/stock-10.9.5/Apple Color Emoji.ttf" \
  --target-os 10.9.5

./build-pkg.command
```

Для сборки непосредственно из Git checkout нужны Xcode Command Line Tools.

Результат:
`dist/Emoji26-Additions-0.2.0-macos10.9.5.pkg`. Он содержит производные данные
глифов Apple и предназначен только для ваших собственных Mac. Не публикуйте,
не загружайте и не коммитьте этот файл.

Сохраните созданный `manifest`: в нём указаны целевая ОС, режим сборки, размер и
SHA-256 шрифта.

## Установка, проверка и удаление

Откройте локально собранный `.pkg` на старом Mac с точно совпадающей версией ОС.
Установщик проверяет версию, x86_64, SHA-256 payload и свободное место, а также
сохраняет предыдущую копию дополнительного шрифта этого проекта. Системные
шрифты Apple и Character Palette не изменяются.

После перезагрузки запустите:

```sh
"/Applications/Emoji 26 Additions/verify.command"
```

Затем вручную проверьте picker и TextEdit. Для удаления:

```sh
"/Applications/Emoji 26 Additions/uninstall.command"
```

Введите указанное подтверждение и перезагрузитесь. Откат затрагивает только
дополнительный шрифт проекта.

## Ограничения отображения

Безопасный payload намеренно исключает ZWJ, variation selectors, skin-tone
modifiers, regional indicators, tags, keycaps и уже существующие legacy
mappings. Поэтому сейчас проект **не заявляет** новые флаги, оттенки кожи,
семейные/профессиональные ZWJ-последовательности или поведение VS15/VS16.
Picker может скопировать последовательность, но это не доказывает, что старый
AppKit способен её отрисовать.

Нативный аудит проверяет `cmap`, `sbix` и `GSUB`. Поведение старого CoreText
нужно визуально проверять отдельно на каждой версии. Успешная установка сама
по себе не является успешным тестом отображения.

## Безопасность и происхождение

- Нет сетевых загрузок и `curl | sh`.
- Не заменяется `/System/Library/Fonts/Apple Color Emoji.ttf`.
- Не меняется база Character Palette.
- Не отключаются механизмы защиты системы.
- Используются точные пути, без рекурсивного удаления и широких glob.
- `.pkg` создаётся только локально; шрифты Apple исключены из Git.
- Перед публикацией bootstrap-архив автоматически проверяется на отсутствие
  файлов `.ttc`, `.ttf`, `.otf` и `.pkg`.

Подход основан на статическом исследовании
[Updated Mavericks Emojis](https://github.com/Wowfunhappy/Updated-Mavericks-Emojis)
и пакета MavericksForever, но использует другую — дополнительную и обратимую —
архитектуру. Подробнее:
[research/MAVERICKSFOREVER.md](research/MAVERICKSFOREVER.md).
